# Фикстурный бэкенд

Реализация контракта `docs/HTTP-API.md` на Node.js без зависимостей. Нужен, чтобы разрабатывать и показывать
интерфейс без Rust, Steam и доступа к Thunderstore.

```bash
node devserver/src/server.js --port 7788
```

* `src/data.js` — игры, пакеты (Lethal Company, R.E.P.O., Risk of Rain 2), профили, установленные моды,
  `.cfg`-файлы, обновления;
* `src/server.js` — маршрутизация, SSE, имитация очереди установки (прогресс каждые ~620 мс), CORS для CEF.

Данные вымышленные по форме, но правдоподобные по содержанию: реальные названия популярных модов, размеры,
рейтинги и деревья зависимостей. Этот сервер **не** является продакшн-бэкендом — им является `backend/`
(демон `galexd`).
